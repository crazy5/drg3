# 批量导入模板说明

## 支持格式

| 格式 | 扩展名 | 备注 |
|---|---|---|
| Excel | `.xlsx` / `.xls` | 第一行为表头，从第二行开始为数据 |
| CSV | `.csv` | UTF-8 编码；分隔符支持 `,` 或 `;` |

---

## 列定义

### 必填列

| 列名（推荐） | 别名（兼容） | 字段 | 说明 |
|---|---|---|---|
| **病案号** | case_id, 住院号, ID | `case_id` | 主键，唯一标识一条病案 |
| **主要诊断** | zyzd, 主要疾病, 主诊断 | `zyzd` | ICD-10 编码，如 `A01.001` |

### 可选列

| 列名（推荐） | 别名 | 字段 | 说明 |
|---|---|---|---|
| 主要手术 | zyss, 主手术 | `zyss` | ICD-9-CM-3 编码，如 `33.5100` |
| 其他诊断 | qtzd, 副诊断, 合并症 | `qtzd_list` | 多值用 `;` 或 `,` 分隔，如 `A02.001;B99.001` |
| 其他手术 | qtss, 副手术 | `qtss_list` | 多值用 `;` 或 `,` 分隔 |
| 年龄 | nl, age | `nl` | 整数，0-120 |
| 性别 | xb, gender | `xb` | `1`=男 / `2`=女 / `9`=未知 |
| 新生儿日龄 | xsrtl | `xsrtl` | 整数，仅新生儿使用 |
| 新生儿体重 | xsrtz, 体重 | `xsrtz` | 整数（克），仅新生儿使用 |
| **入院日期** | admission_date | `admission_date` | `YYYY-MM-DD` / `YYYY/MM/DD` / `YYYYMMDD` / Excel 日期 |
| **出院日期** | discharge_date | `discharge_date` | 同上；用于 Dashboard 按日期范围筛选 |
| **出院科室** | discharge_department | `discharge_department` | 文本，如 `妇科` / `骨科二病区`；用于 Dashboard 按科室筛选 |

> 列名匹配是**模糊匹配**：去除空格、转大写后做子串包含。
> 例 `主要诊断` / `主要疾病` / `ZYZD` / `zyzd` 都能正确识别。

---

## CSV 示例

```csv
病案号,主要诊断,主要手术,其他诊断,其他手术,年龄,性别,入院日期,出院日期,出院科室
C001,A01.001,33.5100,A02.001;B99.001,,35,1,2026-01-05,2026-01-20,呼吸内科
C002,I50.900,,E11.900,I10.200,68,2,2026-02-10,2026-02-25,心内科二病区
C003,N84.001,68.2915,N93.901,E78.200,52,2,2026-03-01,2026-03-05,妇科
C004,P23.600,,,2,0,9,2026-03-10,2026-03-15,新生儿科
```

> ⚠️ 第一个字符是 UTF-8 BOM (`﻿`)，防止 Excel 中文乱码。系统会自动剥离。

## 大小限制

- 单批上限 **10000** 条病案
- 文件大小上限 **20 MB**
- 超出会返回 HTTP 413

---

## 错误处理

| 现象 | 处理 |
|---|---|
| 必填列缺失 | 整条病案跳过，记录到任务的 `error_log` |
| 编码格式异常（如主诊断为空字符串） | 该条 `error_type='error'`，不影响其他病案 |
| 列名无法识别 | 返回 400，提示无法识别的列 |

每条病案独立 try/except，单条失败不阻塞整体。

---

## 结果状态

每条病案分组后有三种状态：

| `error_type` | 含义 | 含义解释 |
|---|---|---|
| `success` | 正常分组 | MDC → ADRG → DRG 三层全部命中 |
| `fallback` | 兜底 | 任一层未命中，分组为 `0000` |
| `error` | 异常 | 病案数据本身有缺陷（如主诊断编码非法） |

前端 Dashboard 兜底率超过 5% 会触发告警。
